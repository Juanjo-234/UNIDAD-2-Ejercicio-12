Resolución del ejercicio N°12 de la unidad 2 de programación.
Este programa simula un sistema de gestión y registro inmobiliario que administra la titularidad de bienes raíces.
Además controla restricciones legales para autorizar o denegar de manera segura las transferencias de dominio entre propietarios a través de un intermediario.

Clases utilizadas:
Propiedad
Propietario
RegistroPropiedad
GestorInmobiliario
